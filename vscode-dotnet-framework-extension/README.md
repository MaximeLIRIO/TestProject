# vscode-dotnet-framework-extension

## Overview
This extension provides a comprehensive offline development environment for .NET Framework projects within Visual Studio Code. It allows users to create test projects, manage solutions, add project references, debug C# code, and explore tests seamlessly.

## Features
- **Create Project**: Easily create new test projects from scratch, selecting the desired .NET Framework.
- **Create Solution**: Set up new solutions to organize your projects effectively.
- **Add Project Reference**: Add references to other projects or libraries directly from the context menu.
- **Debugging Support**: Debug your C# projects with integrated support for breakpoints and step-through execution.
- **Test Explorer**: Manage and run tests with a dedicated interface that displays results in real-time, including options to run individual tests or all tests in a class.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd vscode-dotnet-framework-extension
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Open the project in Visual Studio Code.

## Usage
- Use the command palette (Ctrl+Shift+P) to access the extension commands.
- Create new projects or solutions using the provided commands.
- Right-click on projects in the explorer to add references or debug.
- Open the Test Explorer to view and manage your tests.
