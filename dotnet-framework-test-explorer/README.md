# dotnet-framework-test-explorer

## Overview
The dotnet-framework-test-explorer is a Visual Studio Code extension that provides a test explorer UI for .NET Framework projects. It allows developers to discover, run, and view the results of their unit tests in a user-friendly interface.

## Features
- Discover tests in .NET Framework projects
- Run tests and view results in real-time
- Refresh test lists and results
- Log messages and errors for debugging

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/dotnet-framework-test-explorer.git
   ```
2. Navigate to the project directory:
   ```
   cd dotnet-framework-test-explorer
   ```
3. Restore the NuGet packages:
   ```
   nuget restore
   ```

## Usage
1. Open your .NET Framework project in Visual Studio Code.
2. Launch the test explorer from the command palette (Ctrl+Shift+P) by typing "Test Explorer".
3. The test explorer window will display the discovered tests.
4. Click on a test to run it and view the results.
